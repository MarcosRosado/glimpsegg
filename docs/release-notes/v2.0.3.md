## GlimpseGG 2.0.3

### Changed

- **Glint is fairer across positions.** For the same weight on the win, the score sat 2 to 3
  points high for mids and 2 to 3 points low for offlaners. Now every position has the same
  average. In the match list, the score uses the positions each hero is usually played in, not
  just core or support.
- Glint is still **experimental**: the tooltip shows how it was checked, and it may keep changing
  as more matches are measured.

## Português

## GlimpseGG 2.0.3

### Mudou

- **O Glint ficou mais justo entre posições.** Com o mesmo peso na vitória, a nota saía 2 a 3
  pontos alta para o mid e 2 a 3 pontos baixa para o offlane. Agora toda posição tem a mesma
  média. Na lista de partidas, a nota usa as posições em que cada herói costuma ser jogado, não
  só core ou suporte.
- O Glint continua **experimental**: o tooltip mostra como ele foi conferido, e a nota pode mudar
  de novo conforme mais partidas forem medidas.
