## GlimpseGG 2.0.2

### Added

- **A warning when OpenDota is having trouble.** When OpenDota answers with a server error, a bar
  at the top says it is unstable and some data didn't load, with a **Try again** button. You can
  close it; it comes back if a new error arrives.
- **A warning when loading takes too long.** If the app opens, a profile loads or a match opens and
  nothing shows up after 10 seconds, the app says OpenDota is slow to respond, so you know to try
  again later.

## Português

## GlimpseGG 2.0.2

### Novo

- **Aviso quando a OpenDota está com problema.** Quando a OpenDota responde com erro de servidor,
  uma faixa no topo avisa que ela está instável e que parte dos dados não carregou, com o botão
  **Tentar de novo**. Dá para fechar; o aviso volta se chegar um erro novo.
- **Aviso quando o carregamento demora.** Se o app abre, um perfil carrega ou uma partida abre e
  nada aparece em 10 segundos, o app avisa que a OpenDota está demorando para responder, para você
  tentar mais tarde.
